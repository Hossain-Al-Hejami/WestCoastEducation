# WestCoast Education

A C# console application developed as part of my software development studies at JENSEN YH.

The project is a simple education management system for handling courses, students, teachers, education managers, and administrators.

The main focus of this project was to practise object-oriented programming (OOP) in C#.

## Features

- Add and view courses
- Register and view students
- Manage teachers, education managers, and administrators
- Create classroom and distance courses
- Save and load course information using JSON files
- Navigate through a console-based menu

## Technologies

- C#
- .NET 10
- Object-Oriented Programming (OOP)
- JSON

## Project Structure

The project is organized into separate folders:

- **Models** – Classes representing courses, people, and other data
- **Services** – Handles application logic and data management
- **Interfaces** – Interfaces used in the project
- **Program.cs** – Main application and console menu
- **courses.json** – Stores course data

## Getting Started

Make sure you have the .NET 10 SDK installed.

Clone the repository:

```bash
git clone https://github.com/Hossain-Al-Hejami/WestCoastEducation.git
```

Navigate to the project folder:

```bash
cd WestCoastEducation
```

Run the application:

```bash
dotnet run
```
